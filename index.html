Set up the bridge

Setup · 2 minutes

  1. Install Python 3.9+, then in the QueueLink folder run pip install -r requirements.txt
  2. Start the bridge on your gaming PC: python server.py
  3. Scan the QR code it prints with your phone, or enter the address and PIN below.
